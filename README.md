# 🩵굴따🩵 (Campfire Diorama)

돌 아치 아래, 강이 내려다보이는 야영지 그림 한 장으로 만든 인터랙티브 페이지입니다.
그림은 평소엔 고요하게 멈춰 있다가, **모닥불 · 침대 · 밤하늘 · 물웅덩이 · 랜턴 ·
천막 자락** 여섯 지점을 클릭하면 그 자리에서 각기 다른 애니메이션이 재생됩니다.
배경에는 은은한 로파이 루프 음악을 깔 수 있습니다 (우측 상단 ♪ 버튼).

CSS로 흉내 낸 이펙트가 아니라, **실제 픽셀아트 프레임으로 만든 GIF**가 재생되는
방식입니다. 원본 그림을 지점별로 분할하고, 그 픽셀을 직접 조작해서(불꽃은 프레임마다
높이를 다시 그리고, 랜턴은 흔들리는 진자처럼, 천막은 바람에 나부끼는 파도처럼 픽셀
자체를 이동시키는 식) 진짜 프레임 애니메이션을 만들었습니다.

화면은 디바이스 높이에 맞춰 항상 꽉 차게 표시되고(비율은 그대로, 자르거나 늘리지
않음), 빌드 도구나 프레임워크 없이 순수 HTML/CSS/JS로만 만들어져 있어서 정적 파일
그대로 어디에나 올릴 수 있습니다.

## 여섯 가지 인터랙션

| 지점 | 클릭하면 | 방식 |
|---|---|---|
| 🔥 모닥불 | 여러 갈래의 불꽃이 각자 다른 리듬으로 3.5초 넘게 이글이글 타오릅니다 | `fx-fire.gif` (32프레임) |
| 🛏️ 침대 | 픽셀아트로 그린 "z" 글자들이 베개 위로 떠오르며 흐려집니다 | `fx-bed.gif` (23프레임) |
| 🌌 밤하늘 | 별똥별 하나가 도시의 불빛 위로 스쳐 지나갑니다 | `fx-star.gif` (16프레임) |
| 💧 물웅덩이 | 동심원 파문이 잔잔한 물 위로 퍼져나갑니다 | `fx-puddle.gif` (20프레임) |
| 🏮 랜턴 | 랜턴이 진자처럼 흔들리다 서서히 멈추고, 불꽃도 함께 깜빡입니다 | `fx-lantern.gif` (28프레임) |
| ⛺ 천막 자락 | 바람이 한 번 훑고 지나가며 천이 물결치듯 나부낍니다 | `fx-tarp.gif` (22프레임) |

각 인터랙션마다 화면 하단에 짧은 한 줄 문장(flavor text)이 함께 떠오릅니다.
모든 GIF는 루프 없이 "한 번만 재생하고 멈추는" 방식입니다.

## 배경 음악

우측 상단의 ♪ 버튼을 누르면 최소한의 요소로 합성한 로파이 루프(부드러운 재즈 코드
패드 + 바이닐 노이즈/크랙클)가 재생됩니다. 브라우저의 자동재생 정책 때문에 반드시
사용자가 직접 눌러야 시작되고, 다시 누르면 멈춥니다.

## 로컬에서 열어보기

```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

빌드 과정이 없으므로 `index.html`을 브라우저로 바로 열어도 대부분 동작하지만,
폰트/오디오 로딩 등을 위해 로컬 서버 사용을 권장합니다.

## 폴더 구조

```
campfire-diorama/
├── index.html               # 페이지 구조 + 6개 클릭 핫스팟 + fx 컨테이너 + BGM 버튼
├── style.css                  # 팔레트・타이포・레이아웃(풀스크린)
├── script.js                    # 클릭 → GIF 재생 / BGM 재생-정지 토글
├── assets/
│   ├── scene.png             # 배경 원화
│   ├── bgm.mp3                # 합성한 로파이 배경음악 루프 (16초)
│   ├── fx-fire.gif             # 모닥불이 이글이글 타오르는 애니메이션 (투명 배경)
│   ├── fx-bed.gif              # 침대 위 zzz 애니메이션 (투명 배경)
│   ├── fx-star.gif             # 별똥별 애니메이션 (투명 배경)
│   ├── fx-puddle.gif           # 물웅덩이 파문 애니메이션 (투명 배경)
│   ├── fx-lantern.gif          # 랜턴 흔들림 + 불꽃 깜빡임 (투명 배경)
│   └── fx-tarp.gif             # 천막 자락이 바람에 나부끼는 애니메이션 (투명 배경)
├── scripts/
│   ├── make_fx_gifs.py         # 모닥불/침대/별똥별/파문 GIF 생성 스크립트
│   ├── make_lantern_tarp.py    # 랜턴/천막 GIF 생성 스크립트
│   └── make_bgm.py             # 배경음악(bgm.mp3) 합성 스크립트
└── README.md
```

## 배포하기 (GitHub Pages)

1. 이 폴더 "안의" 파일들을 저장소 최상위에 그대로 커밋합니다 (폴더째 올리면
   `저장소/campfire-diorama/index.html`처럼 한 겹 더 들어가 버리니 주의).
2. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/root`로 지정합니다.
3. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/`에서 확인할 수 있습니다.

Netlify, Vercel 등 어떤 정적 호스팅에 올려도 별도 설정 없이 그대로 동작합니다.

## 동작 원리 (요약)

- **레이아웃**: `.scene`이 항상 디바이스 높이(100dvh, 구형 브라우저는 100vh로
  대체)를 채우고, 폭은 원본 비율(941:1672)에 맞춰 자동으로 계산됩니다. 상단
  타이틀・BGM 버튼・하단 안내문은 그림 위에 떠 있는 오버레이라 레이아웃 공간을
  차지하지 않습니다.
- **핫스팟**: `index.html`의 `.hotspot` 버튼 6개가 그림 위에 퍼센트 좌표로
  올려져 있고, 각각 `data-target`으로 어떤 GIF를 재생할지 지정합니다. 랜턴과
  천막 핫스팟이 밤하늘 영역과 살짝 겹치는 구간은 DOM 순서로 우선순위를
  정했습니다.
- **fx GIF들은 진짜 애니메이션**: `assets/fx-*.gif`는 모두 원본 그림에서 해당
  영역을 잘라낸 뒤, 픽셀 단위로 새 프레임을 만들어 낸 투명 배경 GIF입니다.
  랜턴은 진자처럼 위쪽 고정점에서 멀어질수록 더 많이 흔들리도록 행(row)마다
  다른 크기로 가로 이동시켰고, 천막은 같은 방식으로 물결치는 위상을 프레임마다
  이동시켜 바람에 나부끼는 느낌을 만들었습니다. 두 경우 모두 원래 물체가 있던
  자리는 주변 배경(벽돌/천 뒤 배경)을 따와 메꿔 넣어(inpainting) 빈틈이 생기지
  않게 했습니다.
- **재생 트리거**: `script.js`가 클릭 시 그 GIF를 가리키는 `<img>`를 매번
  새로 만들어 넣습니다 (캐시 무력화를 위해 `?t=timestamp`를 붙여서, 같은
  클립을 연달아 눌러도 항상 처음부터 다시 재생됩니다). 재생 시간이 지나면
  `<img>`를 제거해 다음 클릭을 기다립니다.
- **배경음악**: `scripts/make_bgm.py`가 numpy/scipy로 코드 패드(트라이앵글파
  두 개를 살짝 디튠해 겹친 소리)와 베이스, 바이닐 히스・크랙클 노이즈를 직접
  합성해서 만든 16초짜리 루프입니다. 루프 시작과 끝을 크로스페이드해서 이어
  붙이는 지점이 튀지 않게 처리했습니다.

## 커스터마이징 포인트

- `style.css` 상단 `:root`의 색상 변수만 바꿔도 전체 톤이 바뀝니다.
- 핫스팟/이펙트 위치는 `index.html`의 `.hotspot`과 `.fx` 인라인 `style`
  (left/top/width/height, 이미지 기준 퍼센트)로 조정합니다. 이 값들은 GIF를
  만들 때 사용한 원본 이미지의 크롭 좌표와 정확히 일치해야 합니다.
- `script.js`의 `CAPTIONS` 객체에서 각 지점의 flavor text를, `FX` 객체에서
  프레임 수/재생 속도를 바꿀 수 있습니다.
- 새 GIF를 만들려면 `scripts/make_fx_gifs.py`(불꽃형 애니메이션)나
  `scripts/make_lantern_tarp.py`(흔들림/물결형 애니메이션)를 참고하세요.
  배경음악 톤이나 길이를 바꾸려면 `scripts/make_bgm.py`의 `CHORDS`,
  `CHORD_DUR` 값을 조정하면 됩니다 (Pillow, numpy, scipy 필요).

## 접근성

- 여섯 핫스팟과 BGM 버튼 모두 `<button>`이라 키보드 탭 이동과 엔터/스페이스로
  조작 가능합니다.
- `prefers-reduced-motion`을 존중해서, 모션에 민감한 사용자에게는 마커의
  숨쉬는 듯한 펄스 등 장식성 애니메이션이 최소화됩니다.
- 배경음악은 절대 자동재생되지 않고, 사용자가 직접 버튼을 눌러야만
  시작됩니다.
